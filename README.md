# Эли и фотон

Детская игра про электрон Эли, свет и атомы. Мир 1, Сцена 1:
«Режем яблоко» → «Собери атом» → «Лесенка Эли» (этапы 1–5).
Язык: пока только иврит (русский спрятан: `RU_ON = false` в `js/game.js`; русские тексты оставлены на потом).

## Запуск

**Проще всего:** двойной щелчок по `play.bat` — он поднимет сервер и откроет игру в браузере
(окно сервера не закрывать, пока играете).

Или вручную — запустить локальный сервер в папке проекта:

```
python -m http.server 8123
```

и открыть http://127.0.0.1:8123/ (русский: http://127.0.0.1:8123/#ru).
Через `file://` (двойным щелчком по index.html) игра идёт, но без озвучки — браузер не даёт читать файлы.

Прогресс (до какой сцены дошли, значок, пойманные цвета штрихкода) хранится в браузере.
Начать с чистого листа: в консоли браузера `localStorage.clear()`.

Сцену можно открыть сразу по адресу: `#ru-apple`, `#ru-build`, `#ru-eli1` … `#ru-eli5`
(или то же с `he-`).

## Устройство

```
index.html     разметка страницы
css/style.css  стили
js/game.js     вся логика игры; в начале файла — описание параметров
js/texts.js    все тексты игры (T_RU, T_HE)
js/sound.js    озвучка фраз и звуковые эффекты (эффекты синтезируются, файлов нет)
audio/he, ru   озвучка фраз (MP3) — делается скриптом, руками не править
tools/         make_voice.mjs — скрипт озвучки
img/           картинки игры (WebP)
art/           оригиналы картинок (PNG); имя = имя картинки в img/
references/    образцы и стоковые фото, старые варианты карточек (не в Git)
```

Оригинала `eli_hello` (Эли машет рукой) в `art/` нет. `photon_violet.webp` — это `photon_violet.png`,
сдвинутый в синеву.

- `P` в начале `js/game.js` — все настраиваемые параметры (размеры, скорости, цвета ступенек).
- `T_RU` / `T_HE` в `js/texts.js` — все тексты игры.

## Озвучка

Каждую фразу героя игра проигрывает из `audio/<язык>/<ключ>.mp3`; дослушав, сама идёт дальше
(ребёнок играет один). Нажатие на говорящего — сразу дальше, кнопка-динамик — послушать ещё раз.

**После любой правки текста** фразы в `js/texts.js` — переозвучить:

```
node tools/make_voice.mjs          # иврит; только новые и изменённые фразы
node tools/make_voice.mjs ru       # русский (на потом)
```

- Иврит — Google Cloud TTS (Chirp 3 HD), через `gcloud` (проект `becky-498719`, как в «Ангельте»).
- Русский — Silero из проекта BaratzNew; перед запуском включить его сервер:
  `cd C:\BaratzNew\web` → `npm run tts:server`.
- Голоса героев (Эли, Атом, рассказчик) — `VOICES` в `tools/make_voice.mjs`; после смены голоса
  просто запустить скрипт снова.
- Новая фраза в игре (новый `say(...)`) — добавить её в `phrases()` в `tools/make_voice.mjs`.
- Послушать все фразы списком, без игры: http://127.0.0.1:8123/tools/listen.html
  (русский — `…/listen.html#ru`).
