# Эли и фотон

Детская игра про электрон Эли, свет и атомы. Мир 1, Сцена 1:
«Режем яблоко» → «Собери атом» → «Лесенка Эли» (этапы 1–5).
Языки: иврит (по умолчанию) и русский.

## Запуск

Игре нужен браузер. Проще всего запустить локальный сервер в папке проекта:

```
python -m http.server 8123
```

и открыть http://127.0.0.1:8123/ (русский: http://127.0.0.1:8123/#ru).

Сцену можно открыть сразу по адресу: `#ru-apple`, `#ru-build`, `#ru-eli1` … `#ru-eli5`
(или то же с `he-`).

## Устройство

```
index.html     разметка страницы
css/style.css  стили
js/game.js     вся логика игры; в начале файла — описание параметров
img/           картинки игры (WebP)
art/           оригиналы картинок (PNG); имя = имя картинки в img/
references/    образцы и стоковые фото, старые варианты карточек (не в Git)
```

Оригинала `eli_hello` (Эли машет рукой) в `art/` нет. `photon_violet.webp` — это `photon_violet.png`,
сдвинутый в синеву.

- `P` в начале `js/game.js` — все настраиваемые параметры (размеры, скорости, цвета ступенек).
- `T_RU` / `T_HE` — все тексты игры.
