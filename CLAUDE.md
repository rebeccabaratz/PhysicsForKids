# «Эли и фотон» — правила проекта для Claude Code

Детская игра по физике (дальше — и по химии) для детей 7–8 лет. Ребёнок играет **один и не читает**:
всё говорит голос, на экране текста нет (кроме большого «איפה אלי?» над яблоком).
Язык — **пока только иврит** (решение автора 2026-11-08): русская кнопка спрятана (`RU_ON = false` в `js/game.js`),
русские тексты в `T_RU` оставлены на потом, новые фразы — только на иврите. Игра работает в браузере телефона/планшета.

- Репозиторий **приватный**: github.com/rebeccabaratz/PhysicsForKids. Единственная версия игры — этот репозиторий
  (артефакт на claude.ai удалён 2026-11-06, не восстанавливать).
- Как запустить, устройство папок, озвучка — **README.md**. Сюжет и будущие главы — **ROADMAP.md**; рассказ с внуками (диалоги, черновик) — **STORY_RU.md, STORY_HE.md**.
- После каждой законченной правки — коммит и push (сообщения коммитов по-русски).

## Как работать с автором

- Отвечать **по-русски**, коротко и конкретно.
- Автор не носитель иврита: ивритские формулировки предлагать **готовыми**, она выбирает **на слух**.
- Физика и химия — **верные**: упрощать можно, утверждать ложное нельзя. Где упрощаем — комментарий
  в коде «что на самом деле». Цифры и факты проверять по источникам, а не по памяти.
- Делать по одной главе/шагу; после шага автор проверяет сама.
- **Кредиты Higgsfield (картинки, видео) — только с разрешения автора**: перед каждой генерацией спросить, что заказать,
  сколько вариантов и сколько кредитов (решение автора 2026-11-11). Сначала искать бесплатный путь (кадры из готовых видео, код).

## Правила игры (решения автора)

- **Пока игра в работе — фразы видны текстом** (`P.SHOW_TEXT = true`, решение автора 2026-11-09): новые фразы пока **не озвучиваем**,
  озвучим всё в конце. Тогда — `SHOW_TEXT = false`: дети не читают, только голос. Фразы всё равно писать по правилам для голоса (ниже).
  Исключение навсегда: буквы элементов на атомах (H, O, Na…).
- **Пока звучит объяснение — всё стоит**: фотоны, корзинки, кнопки появляются после фразы
  (`await say(text, { next: false })`). Фраза с `next: true` идёт дальше сама через 700 мс после голоса.
- Обращение к детям на иврите — **во множественном числе** (לחצו, תסתכלו).
- Результат показывать поведением Эли (радуется / мотает головой), а не табличками.
- Задания: нужная ступенька мерцает. В заданиях «вниз» (фотон-повторюшка) ступенька **не** мерцает:
  дети выбирали фотон её цвета.
- Кнопка «Играть» всегда начинает с яблока (и с пустого штрихкода); «Продолжить» — карта глав (`showMap`, адрес `#he-map`).
  Часть 1 (яблоко → атом → «Эли и свет») идёт подряд, после остальных глав — карта. Главы — `CHAPTERS` в `js/game.js`.
- **Планетарный атом → лесенка** (`planetIntro`) — не менять, автору очень нравится.
- Стиль: объёмный мультяшный (как Pixar), тёмно-синий космос, шрифт Rubik, **жирный не использовать**.

## Озвучка

- Каждая фраза — `audio/<язык>/<ключ>.mp3`, ключ — хэш текста (`voiceKey` в `js/sound.js`).
  После правки текста в `js/texts.js` — `node tools/make_voice.mjs` (по умолчанию только иврит); новая фраза в игре —
  добавить её в `phrases()` в `tools/make_voice.mjs`.
- Иврит — Google Chirp 3 HD, **один мужской голос Puck для всех** (Эли, Атом, рассказчик). Русский (на потом) — Silero `eugene`, `node tools/make_voice.mjs ru`
  (сервер: `cd C:\BaratzNew\web; py -3.14 tts-server/server.py`, порт 8081; запускать и останавливать самому).
- Произношение правится **только для голоса** — правилами `SAY_AS` в `tools/make_voice.mjs`, текст в игре не меняется.
- Правила ивритских фраз:
  - **фразы короткие и простые**: сложные фразы TTS озвучивает неприемлемо;
  - без запятых и без тире — вместо них точки (на запятой голос не останавливается);
  - **без «!»**, без запятых, без тире; старые «!» не трогать без решения автора (там выбраны дубли на слух);
  - числа, на которых голос спотыкается, — словами;
  - имя — «Ellie»/«Elli» латиницей, «פוטוֹן», «אטוֹם», «הכוֹל» (холам на вав, где голос читает «у»).
- Дубли: `--takes N --count 3` → вкладка «Дубли» на `tools/listen.html`; автор выбирает по номеру строки;
  `--pick N=j` ставит дубль в игру и закрепляет его. Номера фраз сдвигаются, когда фразы добавляются или удаляются.
- Послушать всё: `play.bat` (или `python -m http.server 8123`) → http://127.0.0.1:8123/tools/listen.html

## Код

- `index.html` — разметка; `css/style.css`; `js/texts.js` — **все** фразы (`T_RU`, `T_HE`, одинаковые ключи);
  `js/sound.js` — голос и синтезированные звуки; `js/chem.js` — глава «Вещества» (атомы с ручками из проб чата, всё внутри `CHEM`); `js/kids.js` — внуки-герои (`KIDS`: говорят, смеются, едят, моргают, пока ждут — поворачивают голову; анимации «говорит», «стоит», «смеётся» — из видео Higgsfield Kling 3.0 с первым и последним кадром = картинка, кадр 9:16); `js/game.js` — логика, в начале — объект `P` с параметрами
  и заголовок-описание (добавил параметр — допиши в заголовок).
- Сцены: `SCENES = ['apple','build','eli1'…'eli5','fire','chem','react','rainbow','color','uv','sky','leaf','elec','photo','magnet','final']`, адрес `#he-eli3`, `#he-fire`.
  Новая глава: функция сцены (начинается с `clearStage()`, кончается `eliVanish(...)`), добавить в `SCENES` и `SCENE_FN`,
  её фразы — в `phrases()` в `tools/make_voice.mjs`. Проверять без звука: `/?mute#he-<сцена>`; фразы текстом вверху — по-русски (только для автора), `?hetext` — на иврите.
- Хранение в браузере (`localStorage`, всегда в try/catch): `eliLang`, `eliDone`, `eliNext`, `eliBadge`, `eliBarcode`.
- RTL: на иврите `dir="rtl"`; каждому `position:absolute` элементу задавать явные `left`/`top`.
- Физика Эли: уровни водорода `EN(n) = −13,6/n²` эВ; фотоны УФ 10,2 (1→2), красный 656 нм (2→3),
  бирюзовый 486 нм (2→4), фиолетовый 434 нм (2→5); жёлтый и зелёный ни к чему не подходят.
- Перед коммитом: `node --check js/game.js js/texts.js`; проверить на иврите (RTL), ширина ~360–400 px.
- Картинки — WebP в `img/`, оригиналы PNG — в `art/`. Сгенерированные картинки атомов и молекул —
  **пересчитывать частицы**: генератор часто ошибается.
